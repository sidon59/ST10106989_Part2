# Breast Cancer Classification and Model Improvement

## Project Overview
This project uses machine learning to classify breast cancer cases as **Benign (B)** or **Malignant (M)**. It explores data analysis, feature relationships and model performance to identify the most effective classification algorithm.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Machine Learning Models
The following models were trained and compared:
- Logistic Regression
- Random Forest
- Extra Trees
- Gradient Boosting
- XGBoost

## Results
The **Extra Trees Classifier** achieved the best performance with approximately **99.82% test accuracy** and a ROC-AUC score of **1.0000**.

These results require further validation because the dataset contains engineered features and the possibility of data leakage has not been ruled out.

## Project Objectives
- Explore and prepare the dataset.
- Perform exploratory data analysis (EDA).
- Train and compare classification models.
- Evaluate model performance using accuracy and ROC-AUC.
- Identify opportunities for model improvement.
